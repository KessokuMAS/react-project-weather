# 프로젝트 개요
날씨 정보 기반 SPA 구현

CRUD·무한스크롤을 효율적으로 다룬 React 프로젝트


# 기능 소개
날씨 예측 참여 : 사용자가 내일의 날씨를 예측하고 투표하여 포인트를 얻는 시스템.

실시간 날씨 정보 : 서울 및 다른 지역의 실시간 날씨와 예보 제공.

게시판 & 토론 : 날씨 관련 의견을 자유롭게 나누고 토론할 수 있는 공간.

상점 시스템 :  보유한 포인트로 상품을 구매할 수 있게 해주는 심플한 포인트 샵 시스템.


# 핵심 기술 및 구현

1. SPA 구현

2. API 구현

3. CRUD 기능 구현

4. 가상 리스트 렌더링을 이용한 무한스크롤 구현
